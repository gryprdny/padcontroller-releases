# QRT Pad Controller: downloads

Installers for **QRT Pad Controller** by Quarteight Digital, a touch-pad controller for Resolume Arena (OSC) and vMix (HTTP API) that you use from a tablet or phone over WiFi.

This repository only holds the installers. The source code of the app is not published here.

Website: https://controller.qrtdigital.app

## Download

Get the newest version from the **[latest release](https://github.com/gryprdny/padcontroller-releases/releases/latest)**.

| System | File |
| --- | --- |
| Windows | `QRT-Pad-Controller-Setup-<version>.exe` |
| macOS, Apple Silicon (M1 and newer) | `QRT-Pad-Controller-<version>-arm64.dmg` |
| macOS, Intel | `QRT-Pad-Controller-<version>-x64.dmg` |

- **Windows:** the first time, Windows may show "Windows protected your PC". Choose *More info*, then *Run anyway*.
- **macOS:** the app is not signed by Apple, so macOS shows a security warning the first time. Open *System Settings*, *Privacy & Security*, and choose *Open Anyway*.
- **Updates:** the app tells you when a new version is out. On Windows it can download and install the update from inside the app. On macOS it opens the right download for your Mac. Your layouts and license are kept.
- Free to use, with a Pro license for the extra features. Details on the website.

## Unduhan (Bahasa Indonesia)

Ambil versi terbaru dari **[rilis terbaru](https://github.com/gryprdny/padcontroller-releases/releases/latest)**. Pilih file `.exe` untuk Windows, atau file `.dmg` untuk Mac (`arm64` untuk Mac Apple Silicon, `x64` untuk Mac Intel).

- **Windows:** jika muncul "Windows protected your PC", pilih *More info* lalu *Run anyway*.
- **Mac:** aplikasi belum ditandatangani Apple, jadi macOS menampilkan peringatan keamanan saat pertama dibuka. Buka *System Settings*, *Privacy & Security*, lalu pilih *Open Anyway*.
- **Pembaruan:** aplikasi memberi tahu kalau ada versi baru. Di Windows, pembaruan bisa diunduh dan dipasang langsung dari dalam aplikasi. Di Mac, aplikasi membuka unduhan yang cocok dengan Mac Anda. Layout dan lisensi Anda tetap aman.
